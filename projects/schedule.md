# Schedule Studio

Schedule Studio 是轻量的日程管理应用，使用原生 JavaScript ES Modules、HTML 和 CSS 实现年、月、周、日视图，支持任务添加、编辑、筛选和本地保存。

## 交互与数据

- **快速添加**：从输入中解析日期、时间、时长与任务标题，减少在表单中逐项填写。
- **多视图**：同一组任务可按不同时间范围查看，配合标签和完成状态筛选。
- **本地保存**：任务写入 localStorage，并可通过 JSON 导入导出。
- **界面状态**：通过 DOM 事件更新任务、当前视图、主题与语言。

例如，以 2026-06-18 为当前日期，输入：

```text
tomorrow 15:00 study JavaScript 1h
```

解析结果为 2026-06-19 的 15:00—16:00，标题为 `study JavaScript`。检查脚本也覆盖了“明天下午3点 学习 JavaScript 1小时”这一中文表达。

## 模块划分

项目将日期处理、快速输入解析、任务存储、主题和语言逻辑从页面入口中分离。页面负责接收事件与刷新视图，解析和存储模块处理各自的数据规则；样式按基础、组件与视图拆分。

| 位置 | 职责 |
| --- | --- |
| `assets/js/app.js` | 页面入口与事件组织 |
| `assets/js/modules/` | 日期、快速添加、任务与界面功能模块 |
| `assets/js/core/storage.js` | 本地存储 |
| `assets/css/` | 基础、组件和视图样式 |
| `scripts/` | 页面资源与输入解析检查 |

这是已有工程从大入口文件中逐步拆分的结果，便于分别修改交互与数据处理逻辑。

## 运行与检查

```bash
npm ci
npm run dev
```

开发地址默认为 `http://127.0.0.1:5173`。

```bash
npm run check
npm run build
```

`check` 检查页面资源引用和快速输入解析，`build` 检查打包与模块导入。
