# Nuwanda Space

> 项目说明草稿，整理于 2026-11-25。实现与验证范围对应当时的代码快照，可在此继续修改和完善。

使用 Astro / TypeScript 构建的个人内容网站，按内容数据与展示组件分别组织文章、摄影和生活素材。

## 可讨论的工程实践

- 用内容 schema 和目录发现规则管理素材，减少在页面中手动复制内容。
- 通过图库、图片及手绘组件复用展示逻辑。
- 将工程检查、构建和部署脚本作为站点维护的一部分。

当前内容维护有限，公开基线与本地未提交扩展存在差异。本项目作为 Web 工程补充材料，不将本地所有修改描述成已部署，也不作为作品集首屏主项目。

启动与检查命令应在下一次同步实际源码时按 `package.json` 确认；本轮没有安装依赖、构建或发布站点。公开仓库的许可证尚未明确。
